PROJECT 06

Real-Time Object & Face Detection

Sistem deteksi objek dan wajah secara real-time menggunakan webcam laptop dan YOLO. Ketika wajah terdeteksi, sistem mengambil gambar dari kamera dan mengirimkan foto beserta notifikasi melalui Telegram Bot.

Python YOLO YOLO Face OpenCV PyTorch Telegram Bot CUDA

01

Overview

Project ini merupakan pengembangan sistem deteksi objek dan wajah secara real-time menggunakan kamera webcam laptop. Sistem memanfaatkan YOLO untuk mendeteksi objek tertentu, serta YOLO Face untuk mendeteksi wajah pada tampilan kamera.

Objek yang dideteksi meliputi manusia (person), handphone (cell phone), dan remote control. Proses deteksi dilakukan menggunakan Python, Ultralytics, OpenCV, dan PyTorch, dengan pemrosesan memanfaatkan NVIDIA GeForce RTX 4050 Laptop GPU.

Ketika wajah terdeteksi, sistem secara otomatis mengambil gambar dari kamera dan mengirimkan foto beserta notifikasi melalui Telegram Bot. Mekanisme cooldown selama 60 detik diterapkan untuk membatasi pengiriman notifikasi berulang.

03

Sistem & Perancangan

Sistem menggunakan webcam laptop sebagai sumber input video. Setiap frame kamera diproses menggunakan model deteksi objek YOLO dan model YOLO Face untuk mendeteksi objek serta wajah secara real-time.

Hasil deteksi ditampilkan melalui aplikasi yang berjalan pada laptop. Ketika sistem mendeteksi wajah, program mengambil gambar dari kamera dan mengirimkannya bersama notifikasi melalui Telegram Bot. Pengiriman notifikasi dibatasi dengan cooldown selama 60 detik.

Pemrosesan dijalankan pada laptop dengan NVIDIA GeForce RTX 4050 Laptop GPU menggunakan dukungan NVIDIA CUDA. Sistem dikembangkan menggunakan Python dengan pustaka OpenCV, Ultralytics, dan PyTorch.

YOLO Face Mendeteksi keberadaan wajah pada frame kamera.
Python Menjalankan program utama dan mengintegrasikan proses deteksi serta notifikasi.
OpenCV Mengakses webcam dan membantu pemrosesan serta pengambilan gambar dari kamera.
PyTorch dan Ultralytics Mendukung pemuatan dan eksekusi model deteksi yang digunakan sistem.
Telegram Bot API Mengirimkan notifikasi dan foto hasil deteksi wajah ke Telegram.
NVIDIA CUDA Mendukung pemrosesan model menggunakan NVIDIA GeForce RTX 4050 Laptop GPU.

05

Implementasi Program

Program dikembangkan menggunakan Python dengan memanfaatkan Ultralytics, OpenCV, dan PyTorch. OpenCV digunakan untuk mengakses webcam laptop, sedangkan model YOLO dan YOLO Face digunakan untuk mendeteksi objek dan wajah pada frame kamera.

Sistem melakukan deteksi terhadap person, cell phone, dan remote control, serta mendeteksi wajah menggunakan model YOLO Face. Ketika wajah terdeteksi, program mengambil gambar dari kamera dan meneruskan foto beserta notifikasi ke Telegram melalui Telegram Bot API.

Untuk membatasi notifikasi berulang, program menerapkan cooldown selama 60 detik. Dengan mekanisme ini, pengiriman notifikasi tidak dilakukan terus-menerus selama kondisi deteksi masih berlangsung.
